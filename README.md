# Дневник тренировок

Лабораторная работа № 3. Пономарев Никита Сергеевич и Королев Егор Александрович.

Приложение для Android 8.0 и выше. На экране «Журнал» нажмите «Новый подход», заполните дату, упражнение, число повторений и вес в килограммах. Нажмите «Сохранить». Для упражнений без дополнительного веса введите 0. В журнале последняя дата идёт первой. Кнопка «Прогресс» открывает график максимального рабочего веса по дням. Чтобы сменить упражнение, нажмите на его название.

## Устройство проекта

* MainActivity.kt — экраны Jetpack Compose, навигация и отображение графика MPAndroidChart.
* Storage.kt — таблица подходов, DAO, Room и ViewModel с состояниями загрузки, сохранения и ошибки.
* Logic.kt — разбор даты и чисел, нормализация названия упражнения, расчёт дневного максимума.
* app/src/test — восемь тестов правил ввода и расчёта прогресса.
* app/src/androidTest — демонстрационный тест с вводом подходов, выбором упражнения и проверкой ошибки.
* design — три макета в SVG. В Figma создайте пустой дизайн-файл и перетащите три SVG на холст.
* .github/workflows/android.yml — сборка APK и запуск демонстрации на чистом эмуляторе.
* scripts/demo.sh — запись демонстрации. Скрипт очищает данные приложения на подключённом тестовом эмуляторе.

## Сборка на компьютере

Нужны JDK 17, Gradle 8.7, Android SDK Platform 34 и Build Tools 34.0.0. Для первого получения зависимостей нужен доступ к Google Maven, Maven Central, Gradle Plugin Portal и JitPack. Для работы установленного приложения интернет не требуется.

1. Распакуйте архив. Откройте папку TrainingDiary в Android Studio.
2. В настройках Gradle выберите локальную установку Gradle 8.7 и JDK 17. Для командной строки задайте ANDROID_HOME или укажите путь к SDK в local.properties через sdk.dir.
3. Из папки TrainingDiary выполните `gradle testDebugUnitTest assembleDebug`.
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Для установки на подключённое устройство выполните `adb install -r app/build/outputs/apk/debug/app-debug.apk`. Приложение называется «Дневник тренировок».

## Сборка и видео через GitHub

Папка TrainingDiary — самостоятельный Git-репозиторий. Чтобы отправить его в свой пустой репозиторий на GitHub, добавьте его адрес командой `git remote add origin АДРЕС_РЕПОЗИТОРИЯ` и выполните `git push -u origin main`. На вкладке Actions откройте запуск Android. При необходимости разрешите выполнение Actions в настройках репозитория.

Сначала Gradle запускает юнит-тесты и собирает отладочный APK. После успешной сборки в Artifacts доступен TrainingDiary-APK. Затем сценарий устанавливает приложение на чистый эмулятор, вводит контрольные данные, сохраняет снимки экранов и записывает 65 секунд работы. При успешном прохождении демотеста в TrainingDiary-demo будут demo.mp4, пять PNG и test.log. Скачайте результаты запуска для защиты.

Исходники и материалы подготовлены. Результаты запуска Gradle, APK, снимки с эмулятора и видео в исходный архив не включены.
