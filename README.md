# Дневник тренировок

Лабораторная работа № 3. Пономарев Никита Сергеевич и Королев Егор Александрович.

Приложение работает на Android 8.0 и выше. Записи сохраняются в локальной базе Room.

- **Главная.** Календарь показывает дни с записями на выбранной неделе. Стрелки меняют неделю, нажатие на дату открывает дневник за этот день. Под календарём расположены итоги недели и последний подход.
- **Дневник.** Записи сгруппированы по датам. Нажмите «Новый подход» и выберите упражнение из истории. Для нового упражнения введите название в строку поиска и нажмите «Добавить упражнение». Оно появится в списке после сохранения подхода.
- **Графики.** Выберите упражнение. По горизонтали идёт порядковый номер подхода, по вертикали — вес в килограммах. Подходы упорядочены по дате и порядку записи внутри дня. Нажмите на точку, чтобы узнать вес, повторы и дату.
- **Тема.** Шестерёнка открывает выбор светлой или тёмной темы. Выбор сохраняется. На широком экране календарь и сводка расположены рядом, на телефоне — друг под другом.

## Сборка

Нужны JDK 17, Gradle 8.7, Android SDK Platform 34 и Build Tools 34.0.0. При первой сборке нужен интернет для загрузки зависимостей.

1. На Windows распакуйте проект в папку без кириллицы в пути, например `C:\Users\Nikit\Projects\TrainingDiary`.
2. Откройте папку TrainingDiary в Android Studio. В настройках Gradle укажите локальную папку Gradle 8.7 и JDK 17. Выполните **File → Sync Project with Gradle Files**.
3. Выберите эмулятор или подключённое устройство и нажмите **Run ▶**. Для сборки из командной строки запустите `gradle testDebugUnitTest assembleDebug`. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Для обновления установите новую сборку поверх предыдущей с той же подписью. Имя приложения в системе и база подходов сохранились. Очистка данных или удаление приложения удаляет локальные записи.

## Сборка и видео через GitHub

Присоедините свой пустой репозиторий через `git remote add origin АДРЕС_РЕПОЗИТОРИЯ` и выполните `git push -u origin main`. На вкладке Actions откройте запуск **Android**. После успешной сборки в Artifacts появится **TrainingDiary-APK**. После демонстрации на чистом эмуляторе **TrainingDiary-demo** содержит снимки экранов, журнал демотеста и 65-секундное видео. Скрипт демонстрации очищает данные приложения, поэтому запускайте его на тестовом эмуляторе.

## Исходники

- `MainActivity.kt` — вкладки и настройки темы.
- `Home.kt`, `Journal.kt`, `Charts.kt` — главная, дневник и графики на MPAndroidChart.
- `Storage.kt`, `Logic.kt` — ViewModel, Room, проверка полей и сортировка подходов.
- `app/src/test`, `app/src/androidTest` — юнит-тесты и демонстрационный сценарий.
- `design` — макеты экранов для импорта в Figma.
